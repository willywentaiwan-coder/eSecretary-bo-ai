# 博愛國小家長會公開透明會務平台

這是一個純靜態 HTML 網頁，用來呈現博愛國小家長會的會務運作、經費公開、會議紀錄、歷年活動與家長提案入口。

## 檔案

- `index.html`：網頁內容
- `style.css`：版面與視覺樣式
- `script.js`：手機選單與會議紀錄篩選
- `assets/boai-pta-hero.png`：主視覺示意圖

## 建議定期更新

- 家長會組織名單與聯絡窗口
- 家長大會與委員會會議紀錄
- 會費、捐款、活動支出與年度決算摘要
- 園遊會、畢業典禮、志工支援等年度活動成果
- 家長提案的收到件數、處理狀態與回覆摘要

## 使用方式

直接打開 `index.html` 即可瀏覽，不需要安裝套件或啟動伺服器。

目前提案表單是靜態示意，尚未串接 Google 表單、資料庫或後端服務。
